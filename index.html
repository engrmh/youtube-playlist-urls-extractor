Youtube URL extractor

This script extracts all the Video URLs from a given Page.
Just enter the URL in the Field
You can enter any URL, not only Youtube Pages
This website doesn't use any youtube API and will extract the URLs from the raw page source. Note: Due to CORS restrictions, this may not work with all websites.
